# 퀵 루프 (Quick Loop)

로우폴리 3D 배달 타임어택. macOS 네이티브 (Godot 4.7).
식지 않게, 죽지 않게, 늦지 않게.

## 인게임 튜토리얼

**처음 실행하면** 첫 주문과 함께 단계별 안내가 화면 중앙에 뜬다.
튜토리얼이 진행되는 동안에는 **제한시간이 멈춘다.**

W 출발 → A/D 조향 → 픽업 → E 부스터 → SPACE 점프 → 배달 → ESC 메뉴 안내 (7단계).
각 단계는 실제로 그 동작을 해야 넘어간다. **ESC 로 언제든 건너뛸 수 있다.** 완료하면 `user://` 에 기록되어 다음부터는 안 뜬다.
설정 탭의 "튜토리얼 다시 보기" 로 언제든 다시 띄울 수 있다.

## 결과 화면

- **별점은 GTA 수배 레벨 스타일로 항상 만점** (★ 다섯 개, 금색 + 두꺼운 검정 외곽선).
  평가는 별이 아니라 아래 문구로만 한다
- 통계는 6줄로 나눠서 표시한다. 한 줄에 다 넣었더니 **화면 좌우로 잘려나갔다**
- 좌우 70px 여백 + `AUTOWRAP_WORD_SMART` 로 긴 문구도 안 잘린다

`resultshot` 인자로 통계를 가득 채운 상태의 결과 화면을 확인할 수 있다.

## 구역 이동은 '새 날' 이 아니다

메뉴 [구역] 탭에서 다른 구역으로 출근해도 **소지금과 업그레이드가 그대로 유지된다**
(`start_game(keep_progress := true)`). 배달 건수 · 연속 · 경과 시간만 초기화된다.

초기 구현은 그냥 `start_game()` 을 불러서 **구역을 바꿀 때마다 번 돈이 0 으로 날아갔다.**

## 구역 해금 연출

해금 조건(누적 수익)을 처음 넘긴 순간 전체화면 연출이 뜬다. 아무 키나 누르면 닫히고,
6초가 지나면 저절로 닫힌다. 연출 중에는 차가 멈춘다.

| 구역 | 그림 | 문구 |
|---|---|---|
| 배그 전장 | 소총 | "모아둔 돈으로 총을 샀습니다" |
| 마초 트럭장 | 펀치 기계 | "모아둔 돈으로 펀치 기계를 샀습니다" |
| 그 외 | 배달 상자 더미 | "새 배달 구역이 열렸습니다" |

그림은 `ColorRect` 조합이다. 컨테이너 안에서 `position` 을 직접 주면 레이아웃이 덮어쓰므로
**앵커를 0.5(가로 중앙)로 두고 offset 으로 배치**한다.

한 번 본 연출은 `user://` 에 기록되어 다시 안 뜬다.
**설정 탭 → "해금 연출 다시 보기"** 로 언제든 두 연출을 차례로 볼 수 있다.

초기 구현은 **연출이 한 번도 안 떴다.** `_check_district_unlocks()` 가 UI 가 만들어지기 전
(부팅 중)에도 호출되는데, 거기서 `seen` 플래그를 먼저 찍고 나서 연출을 요청했다.
`cut_root` 가 아직 null 이라 연출은 무시되고 플래그만 남아 영영 안 뜨게 됐다.
지금은 **실제로 표시할 때만 플래그를 찍고**, 부팅 시에는 `silent` 로 조용히 흡수한다.

**참고**: 구역 해금은 누적 수익 기준이라 이 연출에서 실제로 돈이 빠져나가지는 않는다.
구매 장면은 연출이다.

## 목표 금액 표시 위치

- **HUD (좌상단)** — 진행 바 + **남은 금액만**. 주행 중에 필요한 건 "얼마 더 벌어야 하나" 뿐이다
- **ESC 메뉴 헤더** — 보유 금액 · **1일차 목표 금액** · 달성률(%) · 남은 금액 · 누적 수익.
  어느 탭에 있든 보인다

## 게임 메뉴 (ESC)

게임 중 **ESC** 를 누르면 메뉴가 열린다. 5개 탭으로 구성.

| 탭 | 내용 |
|---|---|
| 스토리 | 오프닝 스토리 다시 보기 |
| 튜토리얼 | 조작 · 배달 · 식음 · 충돌 · 팁 · 스턴트 · 주문 유형 · 하루의 흐름 · RTX 를 글로 설명 |
| 업그레이드 | 번 돈으로 차를 개조. 8종, 항목별 `Lv.x / y` 표기 |
| 구역 | 6개. 누적 수익으로 해금. 해금된 구역으로 갈아탄다 |
| 도전과제 | 21개. 달성 전에는 이름이 ??? 로 가려진다 |
| 설정 | 튜토리얼 다시 보기 · 이번 판 다시 시작 · 기록 초기화 · 테스트용 소지금 · 해금 연출 다시 보기 |

조작:

- **마우스** — 탭 클릭으로 이동, 업그레이드 행에 올리면 선택되고 클릭하면 구매
- `A/D` 탭 이동
- `W/S` — 업그레이드 탭에서는 항목 이동(선택이 화면 밖으로 나가지 않게 자동 스크롤),
  나머지 탭에서는 본문 스크롤
- `SPACE` 구매, `ESC` 닫기, `Q` 퇴근

행 컨테이너에 `MOUSE_FILTER_STOP`, 그 안의 Label 에는 `MOUSE_FILTER_IGNORE` 를 줘서
클릭이 행까지 내려간다. 선택 이동 후에는 `ensure_control_visible()` 로 스크롤을 맞추는데,
새로 만든 노드는 다음 프레임에야 크기가 잡히므로 `await get_tree().process_frame` 이 필요하다.

## 초기화 (설정 탭)

| 항목 | 지우는 것 | 남는 것 |
|---|---|---|
| 이번 판 다시 시작 | 수익 · 업그레이드 · 배달/충돌 기록 | 도전과제, 최고 기록 |
| 테스트용 소지금 | — (소지금을 1,000만원으로 맞추고 구역 전부 해금) | 전부 |
| 해금 연출 다시 보기 | — | 전부 |
| 기록 초기화 | 최고 기록, 도전과제 달성 (`user://` 세이브 삭제) | 없음 |

**기록 초기화와 이번 판 다시 시작은 두 번 눌러야 실행된다.**
(튜토리얼 다시 보기와 테스트용 소지금은 되돌릴 수 없는 게 아니라 한 번에 실행된다.) 한 번 누르면 빨간 경고가 뜨고, 그 상태에서 다시 눌러야 실제로 실행된다.
탭이나 항목을 옮기면 확인이 취소된다.

## 업그레이드

번 돈을 쓰는 것이므로 100만원 목표와 직접 경쟁한다. 판마다 초기화된다.

| 이름 | 효과 | 외형 변화 | 비용 |
|---|---|---|---|
| 터보 엔진 | 최고속 +5 · 부스터 최고속 +7 | 스포일러 | 12k / 28k / 60k |
| 치킨 파워 부스터 | 연료 회복 +6 · 소모 -20% | 네온 언더글로우 | 12k / 28k / 60k |
| 광폭 타이어 | 조향 속도 +0.45 | 바퀴가 굵어짐 | 10k / 24k / 50k |
| 로켓 노즐 | 점프력 +4.5 | 후미 노즐 | 8k / 20k / 40k |
| 에어백 과다 장착 | 충돌 시간 손해 -30% · RTX 파손비 -30% | 앞뒤 범퍼 | 14k / 34k / 70k |
| 핵융합 보온가방 | 구간 제한시간 +6초 | 배달통이 커짐 | 14k / 34k / 70k |
| 방탄 강판 | 최대 체력 +35 (싸우는 구역 전용) | 철판이 덧대짐 | 20k / 48k / 100k |
| 단골 명단 | 배달 보수 +18% (식은 배달 제외) | 별점 스티커 | 18k / 42k / 90k / 170k |

전부 최대로 올리면 908,000원. 단골 명단만 4레벨이고 나머지는 3레벨이다.
1레벨은 배달 한 건 값(15,000원 안팎)이라 초반부터 바로 붙일 수 있다.
쓴 돈은 그대로 목표에서 빠지므로, 업그레이드로 회수할지 그냥 모을지가 선택이다.

## 도전과제

21개. `user://` 에 저장되어 판이 바뀌어도 유지된다.
달성하면 우하단에 전용 배너가 슬라이드로 올라온다 (일반 잔소리 토스트와 별개 레이어).

기본: 첫 배달 / 단골 확보(연속 10) / 음메(소 10) / 도색 전문가(긁힘 50) /
GTA 하십니까?(대형사고 20) / 냉동창고(식은 배달 5) / 벽돌 제조업자(RTX 3파손 배달) /
무사고 배송(RTX 무파손) / 과속 단속 카메라(200km/h) / 우주여행(체공 2초) /
튜닝의 끝은 순정(업그레이드 6레벨) / 빵빵(경적 30회) / 아이스 에이지!(식은 배달 10건) /
스피드러너(픽업 후 10초 안에 배달) / 곡예 배달(에어타임 보너스 10회) / 팁 부자(팁 누적 10만원) /
1일차 종료

구역 · 격추: 시장 점유율 확보(경쟁사 1대 격추) / 독점 기업(10대 격추) /
이겼닭! 오늘 저녁은 치킨이닭!(배그 전장에서 100만원) / 전국구 배달왕(모든 구역 해금)

## 규칙

1. 초록 기둥(픽업 지점)까지 간다
2. 주황 기둥(고객)까지 배달한다
3. 목표를 잡을 때마다 제한시간이 초기화된다. 거리와 무관하고 누적되지 않는다.
   기본 60초에서 배달 1건당 1.5초씩 줄어들며 30초에서 멈춘다 (20건째부터 30초 고정)
4. **100만원을 벌면 1일차 종료.** 완주 시간으로 별점이 매겨진다
5. ESC를 누르면 언제든 퇴근(중도 종료)할 수 있다

### 시간이 0이 되면 (게임오버 아님)

음식이 **식는다**. 게임은 계속되지만:

- 0초를 넘기는 **그 순간에 딱 한 번** 놀리는 메시지가 뜬다 (음식을 실었으면 "음식 식음", 아직이면 "지각")
- 그 구간의 배달 보수가 **0.001원**으로 떨어진다
- 타이머가 파란색 음수로 바뀌고 미니맵 테두리도 파래진다
- 제한시간은 다음 목표에서 초기화되므로, **다음 구간은 다시 정상 보수다**
- 시간은 -120초에서 멈춘다

### 충돌 3단계

| 단계 | 정면 충격 | 결과 |
|---|---|---|
| 벽 비빔 | 벽에 붙어 계속 주행 | 0.8초마다 비아냥 |
| 긁힘 | 1.5 ~ 15 | 속도만 깎임, 0.25초 손해, 연속 유지 |
| 대형사고 | 15 초과 | 공중제비 + 튕겨나감, 1.5초 손해, 연속 끊김 |

## 실행

에디터에서:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path .
```

빌드된 앱: `~/Desktop/Quick Loop.app` — 처음 열 때 Gatekeeper가 막으면 우클릭 → 열기.

## macOS .app 내보내기

**`build_app.sh` 를 쓰는 게 정석이다.** 그냥 export 만 하면 아이콘이 안 붙는다.

```bash
./build_app.sh
```

스크립트가 하는 일:

1. `icon.svg` 가 `icon.icns` 보다 최신이면 아이콘을 다시 만든다
   (`sips` 로 1024 마스터 → 10개 해상도 → `iconutil` 로 icns)
2. 앱이 없으면 전체 export, 있으면 **pck 만 교체 + icns 복사 + Info.plist 갱신**
3. `xattr -cr` → ad-hoc 서명

수동으로 전체 내보내기만 하려면:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --export-release "macOS" "$HOME/Desktop/Quick Loop.app"
```

유니버설 바이너리(arm64 + x86_64)로 나온다. 서명·공증은 안 되어 있다.

### 아이콘

`application/icon="res://icon.icns"` 로 등록돼 있다. 아이콘은 **앱 번들의
`Contents/Resources/icon.icns`** 라서 pck 교체로는 안 바뀐다. 그래서 `build_app.sh` 가
icns 를 직접 복사하고 `CFBundleIconFile` 을 `icon` 으로 맞춘다.

무엇보다 아이콘은 **작은 크기에서 읽히는 게 전부다.** 그릴 같은 디테일은 512px 로 줄이면
사라진다. 64px 까지 줄여보고 실루엣과 색 대비만으로 트럭으로 읽히는지 확인할 것.

Finder 가 예전 아이콘을 계속 보여주면 캐시 문제다: `killall Dock` 또는
`lsregister -f "<앱 경로>"`.

## 디버그 인자

`--` 뒤에 붙인다. 예: `Godot -- demo shot=/tmp/a.png delay=6`

| 인자 | 설명 |
|---|---|
| `autostart` | 타이틀 건너뛰고 바로 시작 |
| `demo` | 자동 주행 (아무렇게나 달린다) |
| `botplay` | 목표를 향해 직선으로 이동. 배달 루프 로직 검증용 |
| `botspeed=N` | botplay 속도(u/s). 22=허접, 30=보통, 44=고수 |
| `time=N` | 시작 제한시간 (음수도 가능 — 식음 상태 테스트용) |
| `turbo=N` | Engine.time_scale 배속 (최대 20). 긴 판을 빨리 돌릴 때 |
| `events` | 충돌 티어 · 식음 진입 · 구간 제한시간 로그 출력 |
| `story` | 스토리 화면으로 바로 진입 |
| `menutab=N` | 게임 시작 후 N번 탭 메뉴를 연 상태로 (0~3) |
| `legtime=N` | 구간 기본 제한시간 덮어쓰기 (식음 테스트용) |
| `achtest` | 도전과제 배너 확인용 (저장 안 함) |
| `paylv=N` | 단골 명단 레벨 강제 적용 |
| `money=N` | 소지금을 N 원으로 맞추고 구역 해금 갱신 (테스트용) |
| `resultshot` | 통계를 채운 결과 화면 띄우기 |
| `quittest` | 메뉴 Q(퇴근) 가 메뉴를 닫고 결과창으로 가는지 검증 |
| `menurow=N` | 업그레이드 탭 선택 행 지정 (스크롤 확인용) |
| `daytime=N` | 시간대 고정 (0=낮, 0.5=노을, 1=밤) |

## 보수

건당 `9000 + 연속 * 2200 + 속도(km/h) * 45` 원. 여기에 주문 유형 배율과 팁이 곱해진다.
식었으면 0.001원.

팁을 처음 40/25/12%로 넣었더니 봇 기준 7건에 313,000원(기존의 7배)이 나와서
1일차가 절반으로 짧아졌다. 기준을 75/55/35%로 올리고 기본 보수를 25% 낮춰서
다시 20건 안팎으로 맞췄다.
연속을 끊기지 않고 쌓으면 8건 안팎에서 5만원에 도달한다. 5번째가 RTX라 반드시 한 번은 만난다.
충돌로 연속이 자주 끊기면 11건 이상 가면서 10번째 RTX까지 본다.

`SPECIAL_EVERY`(5) / `SPECIAL_PAY`(12,000) / `GOAL`(50,000) 은 서로 맞물려 있다.
RTX 보수가 목표의 1/4을 넘으면 그 한 건이 하루를 끝내버린다 —
목표 5만원에 보수 25,000원으로 돌렸을 때 7건 만에 종료됐다.

## 밸런스 메모

제한시간은 구간당 60초 고정이다. 거리 비례 공식과 누적 압박 계수는 걷어냈다.
(초기 버전은 `직선거리 / 31 + 3`초였는데, 도로를 따라 ㄱ자로 돌아가는 실제 주행거리를
무시한 계산이라 구간당 6~10초밖에 안 줬다.)

검증용 봇(`botplay`)은 직선 관통이 아니라 축을 하나씩 이동하는 ㄱ자 주행을 한다.
`botspeed`는 도로 위 평균 속도를 뜻한다. 26 u/s 기준 구간당 50초 이상 남는다.

## 팁

제한시간을 많이 남기고 배달할수록 팁이 붙는다. 그냥 도착만 하면 되는 게 아니라
서두를 이유가 생긴다.

| 남은 시간 비율 | 팁 |
|---|---|
| 75% 이상 | +30% |
| 55% 이상 | +18% |
| 35% 이상 | +8% |

식은 배달에는 팁이 없다.

## 스턴트

주행 중에 즉시 정산된다. 식은 상태에서는 들어오지 않는다.

| 조건 | 보수 |
|---|---|
| 에어타임 | 0.8초 이상 체공 후 착지. 초당 2,500원 |
| 아슬아슬 | 콘·소 옆 4.6~7.5 거리를 26 u/s 이상으로 통과. 1,400원 (쿨다운 1.6초) |

## 주먹질 (마초 트럭장 전용)

마초 트럭만 팔이 달려 있던 걸 **플레이어 트럭에도 권투 글러브**를 달았다.
**배그 전장에서는 못 쓴다 — 거기는 총으로만 싸운다.**

- 조작: **좌클릭** · **우클릭** · **F**
- 쿨다운 0.55초, 사거리 8유닛, **앞쪽만** (`fwd.dot(to_target) >= 0.35`)
- 데미지 2. 맞은 트럭은 뒤로 22 만큼 밀려난다
- 휘두를 때 글러브가 앞으로 뻗었다 돌아온다
- 허공을 치면 40% 확률로 "허공을 갈랐습니다"
- 결과창에 "날린 주먹 N대" 집계

검증:

| 테스트 | 결과 |
|---|---|
| 마초 트럭 정면 4번 | hp 6 → 격파 (3대 명중) |
| 배그 전장에서 정면 4번 | **명중 0대** (총만 쓰는 구역) |
| **뒤쪽 3번** | hp 변화 없음, **명중 0대** |
| 평화 구역 | 팔 미장착, `can_punch()` false |

### 방탄 강판 검증

| 레벨 | 최대 체력 | 총알 버티는 수 | 누적 비용 |
|---|---|---|---|
| 0 | 140 | 20발 | — |
| 1 | 175 | 25발 | 20,000 |
| 2 | 210 | 30발 | 68,000 |
| 3 | 245 | 35발 | 168,000 |

레벨을 올리면 **늘어난 만큼 현재 체력도 바로 채워준다** (60 → 95 → 130 → 165 확인).

|---|---|---|
| 내 트럭 | 140 | — |
| 배그 경쟁사 | 3 | 총알 3발, 또는 고속 박치기 1번 |

## 내 트럭 체력 (마초 트럭장 · 배그 전장 한정)

평화 구역에는 체력 개념이 아예 없다 (`hp_active()` 가 false). HUD 의 체력 바도 안 뜬다.

| 항목 | 값 |
|---|---|
| 최대 체력 | 140 (방탄 강판 3레벨이면 **245**) |
| 총알 피격 | -7 (20발 버팀) |
| 마초 주먹 | -11 (13대 버팀) |
| 자기장 밖 | **초당 -9**. 제한시간은 안 깎인다 |
| 회복 | **초당 +7** |
| 대파 시 | **보유 금액의 7% 상실**(원 단위 반올림) + 자기장 안쪽에서 재시작 |

회복 조건은 구역에 따라 다르다.

- **배그 전장** — 자기장 **안**에 있으면 무조건 회복
- **마초 트럭장** — 자기장이 없으므로 **3초간 안 맞으면** 회복

체력이 30% 아래로 내려가면 바가 노랗게 바뀌고 숫자가 깜빡인다.

검증:

| 테스트 | 결과 |
|---|---|
| 총 12발 (7씩 84 피해) | 대파 0회, 체력 57 로 생존 |
| 대파 시 금액 | 500,000 → 465,000 (정확히 7%) |
| 자기장 밖 2초 | 체력 140 → 122, 제한시간은 정상 감소(2.0초)만 |
| 안전구역 3초 | 30 → 51 |
| 평화 구역에서 같은 피해 | 체력 유지, 대파 0회, 금액 그대로 |

## 마초 트럭장 — 트럭들이 플레이어와 싸운다

마초 트럭 4대가 **전부 플레이어를 노린다** (예전에는 트럭끼리 마짱을 뜨고
플레이어는 구경만 했다).

- 트럭이 따라붙어 0.9초마다 주먹을 휘두른다. 맞으면 제한시간 -1.2초,
  속도 45% 감소, **옆으로 밀려나고 살짝 뜬다**. 0.55초 무적
- 이 구역엔 총이 없다. **박아서 잡는다** — 속도 16 이상이면 데미지 2,
  30 이상이면 3. 마초 트럭은 hp 6 이라 세게 두 번이면 KO
- KO 하면 45,000원짜리 돈다발을 떨군다
- 결과창에 "주먹 N대" 집계

검증 (트럭 4대에게 포위된 채 7초간 정지):

| 항목 | 결과 |
|---|---|
| 플레이어를 노리는 트럭 | 4 / 4 |
| 얻어맞은 횟수 | 6대 (시간 59.0 → 44.8) |
| 박치기로 KO | hp 6 → 0, 격추 1건 |

실제로는 주먹에 맞으면 밀려나므로 포위가 저절로 풀린다.

## 경쟁사 트럭의 사격 (배그 전장 한정)

배그 전장에서는 트럭들도 총을 쏜다. 마초 트럭장·평화 구역에서는 안 쏜다.

- 사거리 110유닛, 발사 간격 1.1~2.2초 (트럭마다 따로)
- **건물 너머로는 안 쏜다** — 발사 전에 총구→플레이어 레이캐스트로 시야를 확인
- **애임이 형편없다.** 좌우로 0.12~0.26 라디안(7~15도) 흔들리고, 거리가 멀수록 더 흔들린다
- 적탄은 붉은색이라 내 탄(노란색)과 구분된다
- 적탄은 다른 트럭을 통과한다 (자기들끼리 잡아서 돈 떨구면 곤란하다)
- 맞으면 제한시간 -1초, 속도 12% 감소, 0.7초 무적. 결과창에 "피격 N회" 집계

명중률 측정 (정지한 플레이어를 트럭 4대가 32유닛 거리에서 포위, 10초):

| 구역 | 피격 횟수 |
|---|---|
| 배그 전장 | 4~5회 (발사 약 24회 → 약 20%) |
| 마초 트럭장 | 0회 |
| 파스텔 지구 | 0회 (트럭 자체가 없음) |

움직이면서 달리면 이보다 훨씬 덜 맞는다.

**고깔콘은 대사가 없다.** 치면 조용히 날아가기만 한다. 소만 대사가 나온다.

| 긁힘 | 20 | | 지각 | 17 |
| 배달 완료 | 12 | | 벽 비빔 | 10 |
| 착지 | 10 | | 픽업 | 10 |
| 소 | 10 | | | |

`_line()` 은 **셔플백**이다. 묶음을 섞어놓고 하나씩 꺼내므로

## 벽 수집

긁힘과 대형사고 모두 **100원**이 들어온다. 잔소리 대사는 그대로이고 뒤에 금액만 붙는다.
시간 손해(긁힘 -0.25초 / 대형사고 -1.5초)와 연속 배달 끊김은 그대로라서
이득을 보려고 박을 이유는 없다.
결과창에 "벽 수집 N원" 으로 집계된다.

## 주문 유형

배달 구간의 34% 확률로 특수 주문이 붙는다 (RTX 구간 제외). 상단에 분홍색으로 표시된다.

| 이름 | 효과 |
|---|---|
| VIP 주문 | 보수 2배 · 제한시간 30% 삭감 |
| 곱빼기 | 보수 1.4배 · 최고속 0.85배 |
| 국물 요리 | 보수 1.5배 · 충돌 시 시간 손해 2배 |
| 폭우 배송 | 보수 1.6배 · **접지 0.16** (심하게 미끄러짐) |

속도·조향 배율은 업그레이드 값과 곱해지는 별도 레이어(`car.mod_speed` / `car.mod_turn`)라
업그레이드를 덮어쓰지 않는다.

### 미끄러짐 (`car.mod_grip`)

기본 차량은 속도가 차 방향을 그대로 따라가서 **미끄러짐이 아예 없었다.**
`_move_dir`(실제 진행 방향)을 따로 두고 차 방향으로 `slerp` 시킨다.
접지가 낮을수록 늦게 따라와서 차가 옆으로 흐른다.

| 접지 | 고속 선회 중 최대 미끄러짐 각도 |
|---|---|
| 1.00 (평소) | **0.0도** — 기존 조작감 그대로 |
| 0.16 (폭우) | **48.9도** — 차는 안쪽을 보는데 몸은 바깥으로 흐른다 |

`mod_grip >= 0.999` 이거나 공중이면 계산을 건너뛰므로 평소 주행에는 영향이 없다.
`sliptest` 인자로 측정한다.

## RTX 5090 배달

**5의 배수번째 배달**(5, 10, 15…)은 음식이 아니라 RTX 5090이다.

- 픽업 한 구간 전부터 상단에 "다음은 RTX 5090" 예고가 뜬다
- 배달통과 목표 기둥이 검정 + 형광 초록으로 바뀐다
- 보수 60,000원
- **대형사고를 낼 때마다 15,000원씩 깎인다** (최저 5,000원, 에어백 업그레이드로 완화).
  깎일 때마다 "5090이 4090이 됐습니다" → "3090" → "1050 Ti" → "이제 그냥 벽돌입니다"
- 식은 상태로 배달하면 다른 배달과 똑같이 0.001원

## 속도계

`u/s * 3.0`. 기본 최고속 44 u/s = 132 km/h, 부스터 68 u/s = 204 km/h.
(초기 버전은 배율이 8.0이라 300~540 km/h가 찍혔다.)

## 하루의 흐름 (낮 → 노을 → 밤)

배달 건수에 따라 `day_t = deliveries / 16` 으로 진행하며, 실제 값은 초당 0.08 로
천천히 따라가므로 전환이 갑자기 튀지 않는다. 하늘색 · 태양 각도/색/세기 · 앰비언트 ·
안개 · 글로우를 세 단계(`SKY_PHASES`) 사이에서 보간한다.

밤에는 글로우가 0.55 → 1.45 로 올라가서 헤드라이트, 간판, 목표 기둥, 콘이 훨씬 도드라진다.

## 도시 구역 (6종, 누적 수익으로 해금)

도시는 원래도 판마다 새로 생성되지만 색이 늘 비슷해서 반복적으로 보였다.
팔레트를 넣어 건물 색상 범위와 도로 · 인도 · 잔디 색을 통째로 바꾼다.
**1일차 파스텔 지구만 열려 있고, 나머지는 누적 수익이 기준을 넘으면 열린다.**

| 구역 | 보수 배율 | 해금 조건 | 성격 |
|---|---|---|---|
| 파스텔 지구 | 1.0 | 없음 (기본) | 채도 중간, 밝은 회색 도로. **평화 구역 — 사격 금지** |
| 배그 전장 | 2.0 | 누적 10만원 | 자기장 + 3렙 뚝배기. **유일하게 사격 가능** |
| 마초 트럭장 | 2.5 | 누적 30만원 | 팔다리 달린 트럭 7대가 서로 마짱. **사격 금지, 주먹 구역** |
| 단풍 구역 | 3.0 | 누적 60만원 | 주황~노랑 계열만 |
| 해안 신도시 | 3.5 | 누적 100만원 | 청록~파랑 계열만 |
| 흑백 구역 | 4.0 | 누적 200만원 | 무채색. 간판만 컬러로 남는다 |

판 시작 시 "오늘의 구역: N (보수 X.X배)" 로 알려준다.
구역 이동은 **ESC 메뉴의 [구역] 탭**에서 한다. 해금된 구역은 SPACE 또는 클릭으로 출근,
잠긴 구역은 현재 누적 수익 달성률이 %로 표시된다. 이전 구역으로 되돌아가는 것도 자유다.

누적 수익(`career_earnings`)은 배달 · 격추 보상 · 스턴트 · 벽 수집 · 팁을 전부 합산해
`user://quickloop_save.cfg` 에 영구 저장된다. 한 판이 끝나도 사라지지 않는다.
모든 구역을 해금하면 도전과제 "전국구 배달왕"이 열린다.

도시는 `start_game()` 에서 `city.rebuild()` 로 매 판 새로 만든다.
(초기 구현은 `_ready` 에서 한 번만 만들어서, 앱을 껐다 켜야만 구역이 바뀌었다.)

## 드리프트 & 드리프트 부스터 (SHIFT)

`SHIFT` 를 물고 코너를 돌면 뒤가 흐른다. 게이지가 차면 **손을 떼는 순간** 부스터가 터진다.
게임패드는 LB/RB.

| 값 | 의미 |
|---|---|
| `DRIFT_GRIP` 0.30 | 드리프트 중 접지 (평소 1.0). 낮을수록 많이 흐른다 |
| `DRIFT_TURN` 1.40 | 드리프트 중 조향 배수 |
| `DRIFT_MIN_SPEED` 13 | 이 밑에서는 그냥 핸드브레이크. 제자리 돌기 방지 |
| `DRIFT_MAX_ANGLE` 52도 | 이 각을 넘으면 **접지가 다시 살아난다** |
| 단계 | 충전 30 / 62 / 100 = 미니 · 슈퍼 · 울트라 터보 |
| 부스터 시간 | 1.1 / 1.9 / 2.9초. 그동안 최고속 ×1.16, 가속 ×2.4 |

핵심은 `DRIFT_MAX_ANGLE` 이다. 처음엔 접지 0.14 / 조향 1.85 로 넣었더니 미끄럼각이
**113도**까지 벌어져서 드리프트가 아니라 제자리 팽이가 됐다. 지금은 각이 52도를 넘으면
접지를 1.0 쪽으로 되돌려서 44도 근처에 안정적으로 물린다.

충전은 **미끄럼각 × 속도**에 비례한다. 직진으로 붙잡고만 있으면 안 찬다(각 7도 미만은 0).
각이 자리잡는 데 0.5초쯤 걸린다.

부스터가 터지면 `Car.drift_boosted(tier, charge, secs)` 가 나가고, 게임 쪽에서
스턴트 수당(`600 × 단계 × (1 + 물고 있던 초 × 0.25)`)과 대사를 붙인다.
15회 쌓으면 도전과제 "옆으로 배달".

뒷바퀴 옆에 단계 색 스파크가 붙는다(파랑 · 주황 · 보라). 부스터 중에는 노란색으로 길어진다.
HUD 게이지는 물고 있을 때만 나오고, 부스터 중에는 남은 시간으로 바뀐다.

검증 (`drifttest`):

| 항목 | 결과 |
|---|---|
| 같은 입력, 드리프트 OFF | 미끄럼각 **0.0도** / 충전 0 |
| 같은 입력, 드리프트 ON | 미끄럼각 **44도** 로 안정 / 2.6초에 충전 100 (3단계) |
| 릴리즈 | 부스터 2.7초 / **132 → 210 km/h** / 스턴트 2,977원 |
| 충전 속도 (제대로 물린 프레임만) | 48~66/초 → 1단계 0.45~0.62초, 2단계 0.93~1.29초, 3단계 1.5~2.1초 |
| 충전 부족 시 릴리즈 | 부스터 정산 **0회** |

## 시점 전환 (V)

`V` 로 5종을 순환한다. 고른 시점은 `user://quickloop_save.cfg` 에 저장돼 다음 판에도 남는다.

| 시점 | 카메라 | 따라붙는 속도 | 차체 | 운전석 |
|---|---|---|---|---|
| 기본 추격 | 뒤 13.5 · 위 6.2 | 5.5 | 보임 | - |
| 본넷 | 앞 2.2 · 위 2.0 | 22 | **숨김** | - |
| 운전석 1인칭 | 차 위치 · 위 2.4 | 22 | **숨김** | **핸들 + 계기판** |
| 탑뷰 | 위 30 · 뒤 6 | 7 | 보임 | - |
| 시네마 측면 | 오른쪽 14 · 위 4 | 4 | 보임 | - |
| 무지개 환각 | 차 주위 궤도 (반지름 3~16, 높이 -1.4~9.8) | 60 | 보임 | - |

### 운전석 (1인칭 전용)

핸들·대시보드·계기 2개를 `Car._build_cockpit()` 에서 코드로 만든다.

- `_pivot` 이 아니라 **차 노드에 직접** 단다. `_pivot` 에 달면 1인칭에서 차체를 숨길 때
  같이 사라지고, 충돌 스쿼시에 계기판까지 찌그러진다.
- 핸들은 `TorusMesh` + 스포크 3개. 토러스는 XZ 평면에 눕혀 나오므로 X 로 90도 세운다.
- 조향 입력에 따라 핸들이 최대 ±1.9 rad 돈다 (`lerp_angle`, 반응 12).
- 왼쪽 바늘 = 속도 (0~520 km/h), 오른쪽 바늘 = 부스터 잔량. 둘 다 2.2 ~ -2.2 rad 로 매핑.
- 바늘은 emission 을 줘서 밤에도 보인다.

### 무지개 환각

- 카메라가 차 주위를 돈다. 각도 · 반지름 · 높이가 서로 다른 주기(2.3 / 1.21 / 1.73)로
  움직이고, **궤도 각속도 자체도 출렁인다**(`sin(t*0.47)*2.6`). 높이는 지면 아래까지
  내려가서 차를 올려다보기도 한다.
- 바라보는 지점도 흔든다. 차가 화면 가운데 가만히 있으면 하나도 안 어지럽다.
- `look_at` 이 롤을 0 으로 되돌리므로 **그 다음에** `rotate_object_local` 로 기울인다.
  주기를 둘 겹쳐서(1.05 / 0.33) 가끔 화면이 통째로 뒤집힌다.
- 시야각이 26~150 사이에서 출렁인다.
- 화면 덧칠은 **무지개 그라디언트 띠 두 겹**. 가로로 흐르는 띠 + 세로로 흐르는 띠가
  겹쳐서 격자로 일렁인다. 단색을 색만 바꿔 깜빡이면 화면이 그냥 하얘진다.
  화면 두 배 폭/높이로 깔고 한 화면만큼 흘린 뒤 되감아서 이음매를 감춘다.
  `CanvasItemMaterial` ADD 블렌드, 알파 0.28~0.42 + 0.17~0.29.
- 메뉴·결과 화면에서는 끈다. 글자를 못 읽는다.

- 1인칭 계열은 차체가 화면을 가리므로 `Car.set_body_visible(false)` 로 `_pivot` 통째로 숨긴다.
- 1인칭 계열은 따라붙는 속도를 22 로 올렸다. 5.5 로 두면 카메라가 차 뒤에 질질 끌려서
  코너에서 벽 속을 통과한다.
- 탑뷰는 시선이 수직이라 기본 up 벡터와 평행해진다. `look_at(target, -back)` 으로
  차 앞쪽을 up 으로 줘야 화면이 안 눕는다.
- 사격 조준은 화면 레이캐스트라 시점을 바꿔도 그대로 동작한다.

검증 (`camtest`): 6종을 한 바퀴 돌려 카메라 좌표와 표시 상태를 찍었다.
차체가 숨는 것은 본넷·1인칭 두 곳뿐, 운전석은 1인칭에서만, 무지개는 환각에서만 켜진다.
계기 바늘은 속도 2.20 → 1.23 (114 km/h), 연료 -2.20 → 1.15 (부스터 20%) 로 움직였다.
`perf` 프레임 1인칭 60/60, 환각 60/60.

## 엔진 사운드 합성

음원 파일은 안 쓴다. `Car.synth_frames()` 가 `AudioStreamGenerator` 에 샘플을 직접 밀어넣는다.
예전엔 **속도에 비례하는 사각파 하나**였는데, 그건 자동차가 아니라 사이렌 소리였다.

지금 모델:

| 요소 | 내용 |
|---|---|
| rpm | 속도 비율을 **6단 기어 구간**으로 쪼갠다. 경계를 넘을 때마다 rpm 이 떨어져 변속감이 난다 |
| 점화 | 4행정 4기통 = 크랭크 1회전에 2번. 실린더마다 세기가 달라야(1.0/0.88/1.06/0.93) 엔진 소리가 된다 |
| 음색 | 1~6차 배음을 쌓고 soft clip. 사인 하나면 피리 소리다 |
| 저음 | 크랭크 주파수 사인을 섞어 배기관 울림 |
| 소음 | 저역통과한 화이트 노이즈. 스로틀·rpm 에 비례 |
| 머플러 | 1차 저역통과. 스로틀을 닫으면 차단 주파수가 내려가 먹먹해진다 |
| 터보 | 스풀 휘파람 + 흡기 바람 + 블로우오프 + 애프터파이어. **음높이는 안 건드린다** |
| 최고단 끝 | 바늘이 리미터에 7Hz 로 ±110 rpm 깐닥거린다 |
| 경적 | 440 Hz + 554 Hz 2음 화음. 한 음만 쓰면 그냥 삐 소리다 |

### 걸리는 느낌과 부스터 음높이 (고친 것)

처음 넣은 뒤 두 가지 지적을 받았다.

**1. 소리가 툭툭 걸린다.** 원인은 두 개였다.
- **하드 리브 리미터.** 레드존에서 75ms 주기로 연료를 끊었는데, 최고 속도에서 rpm 이
  계속 레드존에 걸려 있어서 **13Hz 로 쉬지 않고 끊겼다.** 빼고 바늘 깐닥임으로 바꿨다.
- **블록 경계의 계단.** 음량·차단 주파수·노이즈 양을 블록마다 새로 계산해서 넣었는데,
  스로틀을 밟고 떼는 순간 값이 그대로 점프했다. 전부 `lerp` 로 따라가게 바꿨다.
- 덤으로 노이즈 저역통과를 0.35 → 0.16 으로 낮춰 쇳소리를 줄이고,
  버퍼를 0.12 → 0.2초로 늘리고 `_process` 에서도 채워서 메뉴·프레임 하락 때
  버퍼가 마르지 않게 했다.

**2. 부스터를 켜면 음높이가 올라가서 이상하다.** 맞는 지적이다.
`engine_rpm()` 에서 부스터일 때 rpm 을 1.12배 하고 있었는데, 터보는 **가속을 돕는 물건**이지
같은 속도에서 엔진을 더 돌리는 물건이 아니다. 배수를 빼고 휘파람과 바람 소리만 얹었다.

측정 (`enginewav=`, 레드존+부스터 구간 포락선):

| | 고치기 전 | 고친 뒤 |
|---|---|---|
| 포락선 변조 세기 | 2013 | **68** |
| 샘플 간 0.12 초과 점프 | 409개 | **176개** |
| 절반 속도 rpm (부스터 끔 / 켬) | 2336 / 2616 | **2336 / 2336** |

### 터보 (부스터 소리)

음높이를 못 올리니(올리면 붕 뜬다) **얹는 소리만으로** 티를 내야 한다. 네 겹이다.

1. **스풀 휘파람** — 밟는다고 바로 최고 회전이 아니다. `_spool` 이 1.3/초로 올라가고
   2.6/초로 빠진다. 휘파람 주파수가 `크랭크 × 11 × (0.55 → 1.30)` 으로 **쓸려 올라간다.**
   0.7% 어긋난 두 음을 겹쳐야 쇳소리가 난다.
2. **흡기 바람** — 저역통과를 **뺀 나머지**(고역)를 쓴다. 같은 노이즈라도 이쪽이 '쉭' 하다.
3. **블로우오프** — 뗄 때 0.38초짜리 '츄'. 부스터를 쓴 티가 제일 크게 나는 소리다.
4. **애프터파이어** — 스풀이 0.6 넘으면 아주 가끔 탁 터진다.

덤으로 배기가 트이는 느낌을 내려고 저역통과 차단을 `_spool × 0.16` 만큼 열고
음량도 `_spool × 0.10` 올린다.

측정 (`enginewav=`, **같은 속도**에서 부스터 끔/켬 비교):

| | 처음(휘파람만) | 지금 |
|---|---|---|
| RMS | +5% | **+22%** |
| 2kHz 이상 비중 | +27% | **+102%** |
| 음높이 | +1.5% | +1.5% (바늘 깐닥임뿐) |
| 뗀 직후 피크 | 0.55 | **0.73** (블로우오프) |

스풀이 실제로 쓸려 올라가는지도 확인했다. 1300~1700Hz(다 감긴 휘파람 자리) 에너지가
**부스터 전 660 → 밟은 직후 862 → 1초 뒤 2087.**

### 파형 테이블

샘플마다 `sin()` 을 8번 부르면 32kHz × 60fps 에서 프레임이 튄다.
실제로 `perf` 하위 5% 가 **42~62** 까지 떨어졌다.
배음 합과 사인을 **1024칸 테이블로 한 번만 구워두고** 색인으로 읽게 바꿔서
하위 5% 가 **83~119** 로 돌아왔다.

`perf` 의 절대값은 그날 기계 상태에 따라 크게 흔들린다(같은 빌드가 60~140 사이).
의미가 있는 건 **같은 자리에서 켜고 끈 비교**뿐이다. 합성을 통째로 끄고 재보면
차이가 없다 (끔 41~63 / 켬 47~67).

### 검증 (`enginewav=경로`)

게임과 **같은 `synth_frames()`** 로 공회전 → 가속 → 레드존 → 부스터 → 스로틀 off → 경적을
10.8초짜리 WAV 로 뽑고, FFT 로 설계값과 대조한다. 따로 만든 테스트용 합성이 아니므로
이 파일이 곧 게임 소리다.

| 항목 | 측정 | 설계 |
|---|---|---|
| 공회전 기본주파수 | 29 Hz | 28.3 (850 rpm) |
| 레드존 기본주파수 | 220 Hz | 220 (6600 rpm) |
| 경적 | 440 Hz | 440 |
| 리미터 변조 | 13.1 Hz | 13.3 (1/0.075초) |
| 고역 비중 (가속 / 스로틀 off) | 0.481 / 0.053 | 닫으면 먹먹해질 것 |
| 피크 / RMS / DC | 0.561 / 0.202 / 0.0003 | 클리핑·DC 오프셋 없을 것 |

가속 구간 기본주파수는 40 → 220 Hz 로 오르되 중간에 136→124, 156→124, 172→132 처럼
**톱니로 떨어진다.** 이게 변속이다.

## 피드백 (juice)

똥겜이라고 손맛까지 똥일 필요는 없다. 충돌·격파·대파에 **여러 채널을 겹쳐서** 때린다.

### 트라우마식 화면 흔들림

예전엔 `shake = maxf(shake, amount)` 에 **매 프레임 난수** 오프셋이었다. 둘 다 틀렸다.

- `maxf` 는 연타가 한 대처럼 느껴진다. **더해야** 맞다 (`shake + amount * 0.55`, 1.0 에서 포화)
- 매 프레임 난수는 지직거린다. 주기가 다른 사인 셋(1.7 / 2.3 / 1.1)을 섞어 매끄럽게
- 세기는 **제곱**(`shake²`). 작은 접촉은 거의 안 움직이고 큰 건 확 때린다
- 카메라 **롤**도 같이 기울인다. `look_at` 이 롤을 0 으로 되돌리므로 그 **뒤에** 얹는다
- 흔드는 건 카메라뿐. 차 트랜스폼은 안 건드린다

### 히트스톱

큰 충격에만 0.05~0.14초 멎는다. 긁힘·범프까지 멈추면 조작이 끈적해진다.

| 이벤트 | 멈춤 | 배속 | 섬광 |
|---|---|---|---|
| 대형사고 (impact > 18) | 0.08초 | 0.06 | 흰색 0.28 |
| 경쟁사 트럭 격파 | 0.10초 | 0.05 | 주황 0.40 |
| 내 차 대파 | 0.14초 | 0.05 | 빨강 0.55 |
| 울트라 터보 (3단) | 0.05초 | 0.12 | - |

함정 둘을 피했다.
- 타이머에 `ignore_time_scale=true` 를 안 주면 **멈춘 동안 타이머도 멈춰서 안 돌아온다.**
- 0.03초 간격으로 두 번 터지면 **먼저 건 타이머가 나중 것 한가운데서 배속을 복구한다.**
  호출마다 id 를 매겨서 **가장 최근 것만** 복구하게 했다.
- `turbo=` 로 배속을 바꿔 놓고 테스트할 때 1.0 으로 되돌리면 그 설정이 날아간다.
  복구 기준값을 따로 들고 있는다.

### 그 외

- 돈 숫자가 늘면 **1.28배로 튀어올랐다가** `TRANS_BACK` 으로 되돌아온다. 선형 트윈은 죽은 느낌이다
- 섬광은 HUD 글자 **아래** 레이어다. 위에 깔면 숫자를 못 읽는다

### 접근성

ESC → 설정에 **화면 흔들림: 끔 / 약하게 / 강하게**. 끄면 흔들림·히트스톱·섬광이 전부 멎는다.
저장되므로 다음 판에도 남는다.

검증 (`juicetest`):

| 항목 | 결과 |
|---|---|
| 연타 누적 | 한 대 0.22 → 세 대 **0.66** (덮어쓰기면 0.22 그대로여야 함) |
| 감쇠 | 0.7초 뒤 0.66 → **0.00** |
| 히트스톱 복구 | 전 1.00 / 중 **0.05** / 후 **1.00** |
| 겹친 히트스톱 | 짧은 것 뒤에 긴 것 → 0.12초 시점에도 **0.05 유지** |
| 흔들림 끔 | 히트스톱 호출해도 배속 **1.00** |

## 아트 방향 — 플랫 셰이딩 + 조명·실루엣

한때 32x32 도트 텍스처(`scripts/tex.gd`)를 삼면 투영으로 발라뒀는데, **「낚시 방법」
(How to Fish, Dazed Games)** 쪽 그림을 보고 방향을 틀었다. 그쪽은 텍스처가 **아예 없다.**
전부 민무늬 플랫 셰이딩이고, 보기 좋은 이유는 따로 있다.

1. 강한 태양 하나 + **선명한 그림자**
2. 절제된 색 (자연색 위주, 악센트 한둘)
3. **덩어리마다 다른 실루엣** — 네모난 게 하나도 없다
4. 작은 소품 밀도

그래서 이 게임은 **절충**을 택했다. 조명과 실루엣은 가져오고, 네온 구역 색은 남긴다.
배그 전장·마초 트럭장·흑백 구역의 특색이 죽으면 안 되기 때문이다.

### 바뀐 것

| | 전 | 후 |
|---|---|---|
| 표면 | 도트 텍스처 삼면 투영 | **민무늬** (창문은 밤 발광 마스크로만 남김) |
| 채도 | 테마 값 그대로 | **×0.82**, 대신 밝기 폭을 넓혀 명암으로 형태를 읽게 |
| 그림자 | 기본 | 4분할 PSSM, 8192 맵, blur 0.6, 최대 거리 220 |
| 태양 | 1.25 | 1.45 |
| 건물 | 박스 (+옥탑 1개) | **옥상 난간 / 모임지붕 / 1층 차양 / 발코니 슬래브** |
| 가로수 | 기둥 1 + 잎 상자 1 | **테이퍼 줄기 + 원뿔 잎 1~2겹** |

`tex.gd` 는 지운 게 아니라 **창문 발광 마스크 생성용으로만** 남아 있다.
낮에는 꺼두고(`City.set_night(0)`), 밤에 0.55까지 올린다.

### 형태를 만들다 깨진 것 둘

- **허공에 뜬 모자.** 난간·지붕을 건물 **밑단** 크기로 올렸더니, 단이 여러 개인 건물은
  위로 갈수록 좁아져서 지붕이 허공에 떠 있었다. 맨 위 단 크기를 따로 들고 가서 고쳤다.
  발코니도 같은 이유로 **한 단짜리 건물에만** 붙인다.
- **옆으로 튀어나온 쐐기.** 경사 지붕을 "4분할 원뿔을 눕히면 삼각기둥"이라 생각하고 눕혔는데,
  4분할 원뿔은 사각뿔이라 눕히면 쐐기가 옆으로 솟는다. 세워서 **모임지붕**으로 바꾸고
  꼭짓점이 박스 네 귀퉁이에 닿도록 외접원 반지름 `sqrt(w²+d²)/2` 를 썼다.

### 드로우콜

장식을 건물마다 `MeshInstance` 로 놓으니 드로우콜이 **1,000~1,800 → 3,300~4,300** 으로 뛰었다.
난간·차양·발코니·옥탑은 전부 박스 + Y 회전이라 **도로 표시용 MultiMesh 에 같이 태웠다**
(`_mark()`). 그 덩어리는 그림자를 켜 둬야 실루엣이 산다.
지붕 확률도 0.6 → 0.4, 나무 아래 잎 덩어리는 50% 만 붙인다.

결과 **2,200~2,600**. 프레임은 이날 기계 상태가 들쭉날쭉해서(같은 빌드가 26~118) 숫자로
비교하지 않았다. 믿을 건 드로우콜 쪽이다.

## 창문 불빛

창문에는 **발광 마스크**를 따로 깐다. 32%의 칸만 흰색으로 찍은 텍스처를 `emission_texture`
로 쓴다. 세기는 `City.set_night()` 이 `_update_daylight()` 에서 받아 한 번에 바꾼다.

낮에 켜두면 햇빛에 더해져서 건물색이 전부 크림색으로 뜬다. 그래서 **낮에는 0**,
밤에 0.7까지 올린다. 머티리얼 목록을 들고 있다가 값만 바꾸므로 매 프레임 비용은 없다.

### SSAO

블록끼리 맞닿는 구석이 안 어두우면 벽과 바닥이 한 덩어리로 붙어 보인다.
`ssao_radius 1.8 / intensity 2.2 / power 1.4`.

비용 측정 (`perf`, 같은 구역 3회):

| | 중앙값 | 하위 5% |
|---|---|---|
| SSAO 켬 | 114~131 | 106~112 |
| SSAO 끔 | 118~141 | 94~141 |

10~15% 쯤 먹지만 둘 다 60 을 한참 넘겨서 켜뒀다.

## 건물 전광판

도시 건물에 **움직이는 LED 전광판**이 붙는다. 이미지 파일은 하나도 안 쓴다.
`ScreenArt`(`scripts/screen_art.gd`)가 `Control._draw()` 로 매 프레임 직접 그리고,
그 `SubViewport` 텍스처를 3D 쿼드에 albedo 로 붙인다.

채널 6종:

| 채널 | 내용 |
|---|---|
| 스크롤 광고 | "퀵 루프 배달원 대모집" + 아래줄 흐르는 자막 |
| 네온 간판 | "24시 국밥". 1.6초 주기로 테두리째 점멸 |
| 주가 티커 | "김밥천국 ▲ 12.4%" + 흔들리는 꺾은선 그래프 |
| 이퀄라이저 | 노래방 광고. 막대 16개가 사인파로 춤춘다 |
| 뉴스 속보 | 빨간 "속보" 박스 점멸 + 우→좌 자막 |
| 가격 광고 | "치킨 9,900원 / 배달비 12,000원" + 맥동 게이지 |

구현에서 중요한 것들:

- **채널당 SubViewport 1개, 총 6개.** 전광판 16장마다 뷰포트를 주면 매 프레임 16장을
  다시 그려야 한다. 텍스처를 돌려 쓰면 같은 채널끼리 화면이 동기화되지만, 도시 전광판이
  원래 그렇게 생겼으니 문제 없다.
- `disable_3d = true` — 2D 만 그리는 뷰포트에 3D 렌더러가 붙을 이유가 없다.
- 쿼드 머티리얼은 `SHADING_MODE_UNSHADED`. 자체발광 화면이라 낮에도 밤에도 같은 밝기다.
  대신 주변을 못 밝히므로 **`OmniLight3D` 를 따로 달아서** 건물 벽에 빛이 번지게 했다.
- 뒤에 검은 **프레임 박스**를 받친다. 없으면 공중에 뜬 종이처럼 보인다.
  프레임은 남으므로 뒤에서 보면 "간판 뒤통수"가 된다 — 의도한 대로다.
- 텍스처 필터는 `NEAREST`. LED 답게 픽셀이 살아 있어야 한다. 가로 스캔라인도 덧그린다.

### 어느 면에 다는가

간판을 아무 면에나 붙이면 옆 건물 벽만 쳐다본다. 그래서 **블록 중심에서 바깥쪽**
(= 도로 쪽) 으로 향한 면을 고른다. 건물의 네 면 후보 중 `블록중심 → 건물` 벡터와
내적이 가장 큰 면을 쓴다.

검증 (`atsign`, 파스텔 지구): 전광판 16장 중 **15장이 정면 16m 가 뚫려 있다.**
나머지 1장은 같은 블록 안 옆 건물에 막힌 것으로, 실제 도시에도 그런 간판은 있다.

상한은 도시당 16장(`City.MAX_SCREENS`). `perf` 로 잰 프레임은 파스텔 60/60,
배그 전장 60/60, 흑백 구역 60/59 로 전광판 추가 전과 같다.

## 배그 전장 (자기장 · 3렙 뚝배기)

2일차 구역. 배틀로얄 패러디.

- 차량에 **3렙 뚝배기**가 씌워진다 — 용접마스크 바이저 + 형광 초록 눈슬릿
- **보라색 자기장 벽**이 배그처럼 **대기 → 수축**을 반복하며 중심째로 이동한다
- **자기장 밖에서는 체력이 초당 9씩 깎인다.** 제한시간은 안 건드린다
- 1.8초마다 경고 팝업 + 토스트 + 미세 흔들림
- 미니맵에 **현재 원(보라)** 과 **다음 원(흰 테두리)** 이 같이 표시된다
- **픽업 지점과 고객은 항상 원 안**에 잡힌다
- **픽업할 때 보급 상자**를 같이 뜯는다 (아래)
- 배그 전장에서 100만원을 달성하면 도전과제 "이겼닭! 오늘 저녁은 치킨이닭!"

### 움직이는 자기장

가운데로만 쪼그라들면 "일단 중앙에 있으면 안전"이라 긴장이 없다. 그래서 배그처럼
**다음 원을 현재 원 안쪽 아무 데나** 잡고, 중심을 통째로 끌고 간다.

| 값 | 의미 |
|---|---|
| `ZONE_WAIT` 17초 | 다음 원이 미니맵에 뜬 뒤 수축 시작까지 |
| `ZONE_SHRINK` 21초 | 중심·반경이 다음 원으로 보간되는 시간 |
| 반경 비율 0.66 | 단계마다 이만큼 줄어든다 (321 → 212 → 140 → 130) |
| `ZONE_MIN_RADIUS` 130 | 하한. 여기 닿으면 크기는 그대로 두고 **중심만 계속 떠돈다** |

하한을 130으로 잡은 이유는 교차로 간격이 `CELL` = 74 이기 때문이다. 이보다 작으면
원 안에 교차로가 1~2개밖에 안 들어와서 픽업과 고객이 같은 자리에 겹친다.
130이면 원 안에 목적지 후보가 9곳 이상 남는다.

목적지는 **다음 원**을 기준으로 고른다. 다음 원은 보통 현재 원 안쪽이라 지금도 안전하고
수축이 끝나도 안전하다. 다만 하한에 닿아 떠도는 단계에서는 다음 원이 현재 원을 벗어날 수
있어서, `City.point_in_circle()` 에 **두 원을 모두** 넘겨 교집합에서 고른다.

### 보급 상자

배그 구역에서는 픽업 지점에 **낙하산 + 주황 상자 + 빨간 연막**이 같이 떨어져 있다.
음식을 집으면 상자도 같이 뜯기고, 6종 중 하나가 무작위로 나온다.

| 보급 | 효과 |
|---|---|
| 3단계 방탄모 | 체력 완전 회복 |
| 8배율 스코프 | 제한시간 +18초 |
| 부스터 연료캔 | 부스트 게이지 가득 |
| 진통제 | 체력 +55 |
| 현금 다발 | +18,000원 × 구역 배수 |
| 치킨 | 체력 +30, 제한시간 +9초 |

상자는 **픽업 지점에만** 놓인다. 고객 집 앞에 보급이 떨어질 이유는 없다.

검증 (`zonetest theme=1`, 120초 빨리감기 2회):

| 항목 | 결과 |
|---|---|
| 자기장 단계 | 3 / 4 단계 진행 |
| 중심 이동 | 원점에서 최대 **84.2 / 115.8** 이동 (0이면 가운데로만 줄어든 것) |
| 목적지가 원 밖 | **0 / 240 샘플** |
| 서로 다른 목적지 | 19곳 |
| 보급 | 87 / 112개 획득, 6종 전부 등장 |

자기장 벽은 **캡 없는 실린더**(벽면만)다. 캡이 있으면 y=0 바닥과 같은 평면에 깔려
z-fighting 이 나고, 알파 양면 메시라 그리기 순서까지 흔들려서 심하게 깜빡였다.
지금은 벽 하단을 0.40 띄우고 Y 스케일을 고정해 지형과 겹치지 않는다.
`bluecheck` 인자로 벽의 y 범위를 확인할 수 있다.

## 레드닷 조준기 (배그 전장, 우클릭)

우클릭을 **물고 있는 동안** 조준경이 열린다. 마초 트럭장에서는 우클릭이 그대로 주먹이다.

배그 그대로 **1인칭 조준**이다. 어느 시점에서 눌렀든 운전석으로 들어간다.

- 카메라가 **운전석 눈높이(차 위 2.4)** 로 붙는다. 차체와 핸들은 숨긴다.
  3인칭에서 시야각만 좁히면 화면 절반을 자기 차 뒤통수가 차지한다.
- 시야각 70 → **48** (약 1.5배). 배율경이 아니라 **시야가 살아야** 한다.
- 마우스를 **가둔다**(`MOUSE_MODE_CAPTURED`). 커서로 조준하는 게 아니라
  마우스를 움직여 **시선을 돌린다**. 좌우 ±83도 · 상하 ±31도까지, 차 방향 기준.
- **총알은 경통 한가운데로 나간다.** 조준 중에는 `_try_shoot()` 에 화면 중앙을 넘긴다.
- 조준기는 `scripts/scope.gd` 의 `_draw()`. 배율경과 달리 **바깥을 안 덮는다**.
  얇은 하우징 링 + 거의 안 보이는 렌즈 코팅(알파 0.035)이 전부다. 시야를 안 잡아먹는 게
  레드닷을 쓰는 이유인데 터널을 그리면 그걸 없애는 꼴이다.
- 레티클은 EOTech 식 **원 + 가운데 점**. 원만 있으면 어디가 위인지 안 보여서 4등분 눈금을
  얹었고, 점은 번지는 빛 → 붉은 코어 → 흰 심지 3겹으로 겹쳐 발광처럼 보이게 했다.
- 창 크기는 화면 높이의 0.24 고정. 줌이 들어와도 안 좁아진다.
- HUD 글자 밑에 깔았다. 경통이 남은 시간·체력을 가리면 안 된다.
- 무지개 환각 시점에서는 조준이 아예 안 열린다. 그쪽이 시야각을 덮어쓴다.

검증 (`aimtest`):

| 항목 | 결과 |
|---|---|
| 배그 전장, 우클릭 유지 | 시야각 70.0 → **48.2 (1.5배)** / 조준기 표시 / 기본 크로스헤어 숨김 |
| 카메라 위치 | 차와의 거리 **14.1 → 2.4**, 운전석 눈높이까지 **0.2** / 차체·핸들 숨김 |
| 마우스 (200, -60) | 조준각 좌우 -0.44 · 상하 +0.13 rad → **시선 26.2도 이동** |
| 55m 트럭에 조준 사격 | **3발째 격파** (2회 반복, 둘 다 3발) |
| 우클릭 해제 | 시야각 70.0 복귀 / 조준기 숨김 / 크로스헤어·차체 복귀 |
| 마초 트럭장 | `can_shoot=false`, 경통 안 열림 (우클릭은 주먹) |
| 무지개 환각 시점 | 경통 안 열림 |

## 사격 (배그 전장 전용)

마우스로 조준하고 좌클릭으로 쏜다. 크로스헤어가 마우스를 따라온다.

- 조준: `cam.project_ray_origin/normal` → y=-1 평면 교차점을 목표로 삼는다
- 총알(`bullet.gd`): 레이캐스트, 속도 180, 사거리 220, 쿨다운 0.16초
- 적중 판정은 `collider is RivalCar` — 소·콘은 안 맞고 경쟁사 차량만 맞는다
- 경쟁사 배달차: HP 3, 순찰 속도 28, 격추 시 **현금 다발 25,000원** 드랍
- **한 대 격추할 때마다 한 대씩 다시 스폰된다.** 판이 끝날 때까지 대수는 그대로다
  (배그 전장 4대 / 마초 트럭장 7대). 리스폰 위치는 플레이어에서 110 이상 떨어진 곳이다

**사격은 배그 전장에서만 허용된다.** `can_shoot()` 하나가 판단하고,
크로스헤어 표시 · 총알 발사 · 적 차량 스폰이 전부 이걸 따른다.

| 구역 | 사격 | 적 차량 |
|---|---|---|
| 파스텔 지구 | 불가 (평화 구역) | 0대 |
| 배그 전장 | **가능** | 4대 (사격 대상) |
| 마초 트럭장 | 불가 (주먹 마짱) | 7대 (서로 붙는다) |
| 나머지 3종 | 불가 | 0대 |

막힌 구역에서 클릭하면 **아무 일도 일어나지 않는다.** 총도 안 나가고 메시지도 없다.
적 차량 스폰은 사격 허용 여부와 **별개 조건**으로 갈라져 있다 — 마초 트럭장은
총을 못 써도 트럭 7대가 돌아다녀야 하기 때문이다.

## 주먹질 (마초 트럭장 전용)

마초 트럭만 팔이 달려 있던 걸 **플레이어 트럭에도 권투 글러브**를 달았다.
**배그 전장에서는 못 쓴다 — 거기는 총으로만 싸운다.**

- 조작: **좌클릭** · **우클릭** · **F**
- 쿨다운 0.55초, 사거리 8유닛, **앞쪽만** (`fwd.dot(to_target) >= 0.35`)
- 데미지 2. 맞은 트럭은 뒤로 22 만큼 밀려난다
- 휘두를 때 글러브가 앞으로 뻗었다 돌아온다
- 허공을 치면 40% 확률로 "허공을 갈랐습니다"
- 결과창에 "날린 주먹 N대" 집계

검증:

| 테스트 | 결과 |
|---|---|
| 마초 트럭 정면 4번 | hp 6 → 격파 (3대 명중) |
| 배그 전장에서 정면 4번 | **명중 0대** (총만 쓰는 구역) |
| **뒤쪽 3번** | hp 변화 없음, **명중 0대** |
| 평화 구역 | 팔 미장착, `can_punch()` false |

|---|---|

## 마초 트럭장

3일차 구역. 팔다리가 달린 트럭이 서로 마짱을 까는 격투장.

- 트럭 7대가 매 프레임 가장 가까운 상대를 `brawl_target` 으로 잡는다 (`_tick_macho_targets`)
- 상대 5.6 거리 안에 들어가면 0.75초마다 주먹을 날려 **HP 1씩 깎는다**
- 마초 트럭은 HP 6 (기본 3 + 3), 격추 보상 45,000원 (기본 25,000원)
- 차체가 갈색, 배달통이 주황으로 바뀌고 팔/다리/주먹이 붙는다
- 붙는 동안 차체가 좌우로 흔들려서 주먹질 모션을 흉내낸다
- 플레이어는 총을 못 쓴다. 멀리서 구경하거나 피해 다니면 된다

## 도로 폭

건물에 자주 박는다는 피드백을 받고 넓혔다. **`CELL`(교차로 간격 74)은 그대로 둬서
배달 거리와 제한시간 밸런스가 흔들리지 않게** 하고, 블록만 줄였다.

| | 전 | 후 |
|---|---|---|
| BLOCK | 56 | **46** |
| ROAD (차도) | 18 | **28** |
| 대로 배율 | 2.15배 (39) | **1.8배 (50)** |
| 건물을 블록 안으로 미는 여유 | 2.0 | **5.5** |

레이캐스트로 잰 **건물 사이 실제 간격**: 일반 도로 37.5 → **47.3**, 대로 55.8 → **69.7**.
(`roadwidth` 인자로 측정한다.)

데모 봇으로 충돌 횟수를 재려 했지만 그 봇은 핸들을 계속 좌우로 흔들어서
도로 폭과 무관하게 박는다. 폭 자체를 재는 게 맞다.

## 성능 — 도로 표시는 MultiMesh

도로를 넓히자 시야가 멀리까지 트이면서 드로우콜이 늘어 **FPS 중앙값이 37, 하위 5% 가 18** 로
떨어졌다. 횡단보도 · 차선 점선 · 가장자리 선 · 로터리 원형 점선을 **MultiMesh 하나**로 합쳤다.
(수천 개를 개별 `MeshInstance3D` 로 놓고 있었다.)

| | 전 | 후 |
|---|---|---|
| FPS 중앙값 | 37 | **59~60** |
| FPS 하위 5% | 18 | **47~59** |
| 드로우콜 | 3,941 | **1,700~2,100** |
| 노드 | 7,069 | **4,400** |

측정은 3초 워밍업 후 180프레임을 모아 중앙값과 하위 5% 를 낸다 (`perf`).
한 번만 찍으면 27~59 로 들쑥날쑥해서 판단할 수 없었다.

## 도로

격자가 완전히 균일하면 도시가 아니라 바둑판으로 보인다. 다음을 넣었다.

- **대로** — `road_width(i)` 가 3칸마다 도로 폭을 2.15배로 준다. 도로 중심선은 격자에 그대로
  두고 **블록 크기만** 줄여서(`_block_rect`) 교차로 좌표와 미니맵이 안 깨진다.
- **대로 차선** — 대로 가운데 잔디 중앙분리대는 **없앴다.** 충돌체가 있어서 대로를 가로지르거나
  좌회전할 때 막혔기 때문이다. 대신 중앙 점선 2줄 + 차선 분할선을 깔아 폭을 살린다.
- **점선 차선** — 일반 도로는 노란 점선, 모든 도로에 흰 가장자리 선.
- **횡단보도** — 모든 교차로 네 방향에 흰 줄무늬.
- **가로등 · 가로수** — 블록 인도 가장자리를 따라 15 간격으로 번갈아 놓는다.
  (초기 구현은 도로 전체 길이를 30 간격으로 훑어서 **교차로 한복판에 가로등이 떠 있었다.**
  블록 기준으로 바꿔서 항상 인도 위에 선다.)
- **공원** — 잔디, 나무, 연못.

블록마다 크기가 달라지므로 건물 배치 한계는 상수가 아니라 `_lim` (블록별로 계산) 이다.

## 로터리 / 삼각 교차로

대로가 끼는 교차로(`i % 3 == 0 or j % 3 == 0`)의 55% 확률로 교통섬이 생긴다.
`CylinderMesh.radial_segments` 를 28 로 하면 동그란 로터리, 3 으로 하면 삼각 교차로다.

- **로터리** — 잔디 원형 섬 + 중앙 기념물. 55% 소 동상, 45% 오벨리스크(끝이 발광)
- **삼각 교차로** — 삼각 프리즘 섬 + 가운데 나무
- 둘 다 둘레에 흰 점선을 원형으로 깐다 (각 조각을 접선 방향으로 회전)

- **기념물 3종** — 소 동상 38% / 분수대 32% / 오벨리스크 30%

삼각형은 콜리전이 원기둥이라 외접원으로 잡으면 모서리 바깥에서도 막힌다.
반지름을 0.62배로 줄여 내접원에 가깝게 맞췄다.

### 가로등 · 가로수는 쓰러진다

차가 닿으면 **저항 없이** 옆으로 눕는다. 속도가 전혀 깎이지 않는다.

- 전용 물리 레이어(`City.BREAKABLE_LAYER = 4`)에만 올리고 차의 `collision_mask` 에는 없다.
  즉 물리적으로 차를 막을 방법이 없다 (마스크 1 & 레이어 4 = 0).
- 감지는 매 프레임 거리 검사가 아니라 **차 주변 박스 쿼리 한 번**으로 한다.
  물체가 수백 개라 전부 도는 건 낭비다.
- 쓰러지면 콜리전을 제거해서 총알도 통과한다.
- 결과창에 "쓰러뜨린 가로등·가로수 N개" 로 집계된다.

### 턱 올라타기

CharacterBody3D 는 수직 단차를 못 올라간다. `Car._try_step_up()` 으로 직접 처리한다.

1. **수직 벽에 정면으로 막혔는가** (`|n.y| < 0.6` 이고 `impact > 0.3`) — 바닥 접촉은 여기서 걸러진다
2. 위로 `STEP_HEIGHT`(1.15) 만큼 들어올릴 공간이 있는지 `test_move`
3. 올린 높이에서 진행 방향으로 1.3 만큼 갈 수 있는지 — **건물은 여기서 막혀서 그대로 충돌 처리된다**
4. **그 자리 바로 아래에 바닥이 있는지** `test_move(DOWN)` — 허공/지오메트리 안이면 포기
5. 바닥 바로 위에 내려놓고 `velocity.y` 를 0 이하로 깎는다 (턱은 점프가 아니다). 0.3초 쿨다운

초기 구현이 1번과 4번을 빠뜨려서 두 가지가 터졌다.
1번이 없으니 **바닥 접촉도 "막힘" 으로 세어 평지에서 매 프레임 1.15 씩 튀어올랐고**(껄떡거림),
4번이 없으니 지오메트리 안에 올려놓고 물리 엔진이 밀어내면서 40 u/s 에서 **21 유닛까지 솟구쳤다.**

속도와 무관하게 올라간다. 검증 (인도 턱 0.9 기준):

| 속도 | 결과 |
|---|---|
| 3 u/s | 올라탐 (상승 0.96) |
| 6 u/s | 올라탐 (상승 0.96) |
| 12 u/s | 올라탐 (상승 0.96) |
| 24 u/s | 올라탐 (상승 1.30) |
| 40 u/s | 올라탐 (상승 3.27) |

## 부스터 시야각

E 로 부스터를 켜면 FOV 가 **+12도** 벌어진다 (같은 속도 40 기준 75.5 → 87.6).
전환도 더 빠르게(보간 4 → 6) 해서 누르는 순간 확 열린다.

평지 직진 150프레임에서 올라타기 발동 **0회** — 껄떡거리지 않는다.
`steptest` / `flattest` / `steptest nostep` (기능 끄고 비교) 인자로 검증한다.

턱을 올라타면 그 프레임의 충돌 판정은 건너뛴다 (턱은 사고가 아니다).
건물 충돌은 그대로 살아있다 — 데모 주행 검증에서 대형사고 6회 / 긁힘 5회 발생.

### 충돌 판정

가로등 기둥, 나무 줄기, 동상, 분수대, 오벨리스크, 받침대 전부 충돌체가 있다.
(초기 구현은 전부 `solid=false` 라 **그냥 통과했다.**)
소 동상은 박스 조각마다 붙이면 노드만 늘어나므로 몸통 전체를 감싸는 `_collider()` 하나로 처리한다.
`colcheck` 인자로 교통섬 중앙에 충돌체가 있는지 샘플 검사할 수 있다.

**교통섬이 놓인 교차로는 배달 목표에서 제외한다.** 안 그러면 섬 한가운데가 목표로 잡혀서
도달 판정(8.0)에 못 들어간다. 내부 교차로 36개 중 10~12개가 섬이 되고 24~26개가 목표로 남는다.

## 성능

도시 노드 약 5,100개, 드로우콜 약 3,800, StaticBody3D 약 1,150개. 60fps 상한에 붙는다.

충돌체를 붙이자 55fps 로 떨어져서, 맵 바깥 테두리 교차로의 횡단보도를 빼고
횡단보도 줄 간격(3.0 → 4.6)과 차선 점선 간격(10.5 → 15)을 넓혀 되돌렸다.
더 줄여야 하면 가로등 · 가로수 · 횡단보도를 MultiMesh 로 묶는 게 가장 효과적이다.

## 화면 흔들림

| 상황 | 창모드 | 전체화면 |
|---|---|---|
| 대형사고 · 맵 밖 추락 | 흔들림 | 흔들림 |
| 긁힘 · 착지 · 소 접촉 | 흔들림 | **안 흔들림** |

전체화면에서는 화면이 커서 잔흔들림이 부담스러우므로 큰 충돌만 남겼다.
`_shake(amount, big)` 한 곳에서 `DisplayServer.window_get_mode()` 로 판단한다.
`shakecheck` 인자로 두 모드를 자동 전환하며 검증할 수 있다.

## 도시 생성

블록마다 5가지 배치 중 하나를 뽑는다.

| 배치 | 확률 | 내용 |
|---|---|---|
| park | 7% | 잔디 + 나무 4~7그루 |
| tower | 23% | 중앙 고층(42~78) + 주변 저층 3~5채 |
| row | 32% | 한 축을 따라 건물 3~5채, 65% 확률로 뒷줄까지 2줄 |
| cluster | 32% | 제각각 돌아간 건물 8~13채가 빽빽하게 |
| plaza | 6% | 가운데를 비우고 가장자리에 4~6채 |

건물은 확률적으로 계단식(2~3단)으로 올라가고, 34 이상이면 35% 확률로 유리 재질이 된다.
옥탑 60%, 간판 45%. y축 회전이 들어가며 콜리전도 같이 회전한다.
도로로 삐져나오는 것은 `_clamp_in_block()` 이 막는다. 회전한 박스의 **축정렬 AABB**
(`(w*cos + d*sin)/2`)를 써서 블록 안쪽으로 밀어넣는다.

초기 버전은 반대각선(`sqrt(w² + d²)/2`)을 썼는데, 이게 과도하게 보수적이라
20x20 건물이면 중심에서 9 이내에만 놓을 수 있었다. 대부분의 배치 시도가 탈락해서
블록이 텅 비었다. AABB로 바꾸고 탈락 대신 안쪽으로 밀어넣도록 고치니 밀도가 정상화됐다.

```
project.godot        프로젝트 설정 (중력 0 — 차가 직접 처리)
main.tscn            Node3D 하나 + game.gd. 나머지는 전부 코드 생성
build_app.sh         빌드 + 아이콘 생성 + 번들 갱신
icon.svg             아이콘 원본 (SVG)
icon.icns            빌드된 아이콘 (앱 번들이 실제로 쓰는 것)
export_presets.cfg   macOS 내보내기 설정 (아이콘 경로 포함)
scripts/game.gd      상태머신, UI, 배달 루프, 카메라, 자기장, 사격, 저장
scripts/car.gd       아케이드 차량 (CharacterBody3D 가짜 물리) + 생성 오디오 엔진음 + 뚝배기
scripts/city.gd      절차적 도시, 경계벽, 소·콘 배치, 구역 테마 6종
scripts/rival_car.gd 경쟁사 배달차 AI + 마초 트럭 (순찰 / 마짱)
scripts/bullet.gd    레이캐스트 총알
scripts/money_drop.gd 현금 다발 드랍 수거
scripts/menu.gd      ESC 메뉴 6탭 (스토리/튜토리얼/구역/업그레이드/도전과제/설정)
scripts/minimap.gd   미니맵 (커스텀 _draw)
scripts/scope.gd     배그 전장 레드닷 조준기 (커스텀 _draw)
scripts/screen_art.gd 건물 전광판 화면 (_draw 로 그려 SubViewport 에 담는다)
scripts/tex.gd       32x32 도트 텍스처를 코드로 생성 (파일 없음)
ui/kr_theme.tres     SystemFont 기반 한글 테마
```

폰트는 시스템 폰트를 참조한다.
